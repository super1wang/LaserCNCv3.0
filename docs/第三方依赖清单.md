## 操作系统基础能力

| 名称 | 平台 | 用途 | 边界 |
|---|---|---|---|
| Windows CNG / bcrypt | Windows SDK 10.0.26100.0 | SHA-256 强内容摘要 | 仅 `src/infrastructure/hash/windows/` 使用 CNG 类型；Kernel 只依赖 IHashService 与 ContentDigest |
| Windows 文件 API | Windows SDK 10.0.26100.0 | Snapshot 临时写入、flush 与原子发布 | 仅 `src/infrastructure/persistence/filesystem/windows/` 使用 Win32 文件句柄；Kernel 只依赖 ISnapshotStore |

Windows CNG 与文件 API 属于目标操作系统 SDK，不是下载的第三方包。更换平台时应新增相应 IHashService、ISnapshotStore Adapter，不得改变 Snapshot、Journal 或 ContentDigest 公共契约。

Phase 3 验收已证明 `LCNC_BUILD_TESTING=OFF` 时不会获取或生成 Catch2；GitHub 生产依赖均禁用上游子模块递归获取。版本升级必须作为独立变更，重新核对许可证、摘要与 Debug/Release/Production-only 门禁。
