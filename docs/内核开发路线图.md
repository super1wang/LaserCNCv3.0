# LaserCNC Application Kernel 开发路线图

状态定义：`已验收` 表示代码、自动化测试和文档均达到本阶段门槛；`进行中` 表示正在实现；`未开始` 表示不得提前扩展；`延后` 表示有意不在当前里程碑实现。

| 阶段 | 范围 | 状态 | 验收门槛 |
|---|---|---|---|
| Phase 1 | StrongId、Value、Result、Error、Schema | 已验收 | C++20 编译；单元测试；公共 API 无第三方类型；中文文档 |
| Phase 2 | AppKernel、ServiceRegistry、ModuleRuntime | 已验收 | 依赖 DAG、生命周期、冻结与失败回滚测试 |
| Phase 3 | spdlog、JSON、TOML、SQLite、线程池 Adapter | 已验收 | 版本锁定；错误转换；实现可替换；依赖清单完整 |
| Phase 4 | Document、ObjectRegistry、Revision、Transaction | 未开始 | 原子提交、冲突检测、提交后事件规则 |
| Phase 5 | CommandRuntime、QueryRuntime、EventBus | 未开始 | Headless/CLI 共用入口；发现协议；端到端 CTest |
| Phase 6 | TaskRuntime、Scheduler、Cancellation、Resource | 未开始 | 有界关闭、协作取消、进度单调、资源仲裁 |
| Phase 7 | Trace、Metrics、Diagnostics | 未开始 | 观测不改变业务控制流；关键链路 TraceId 完整 |
| Phase 8 | Snapshot、Journal、SQLite Persistence、Crash Recovery | 未开始 | 重放、恢复、校验和、故障注入测试 |
| Phase 9 | Workflow Runtime、Script Runtime | 未开始 | 条件、等待、重试、取消、检查点、补偿测试 |
| Phase 10 及以后 | CAD/CAM/GUI/RPC/AI 等上层能力 | 延后 | 不属于当前内核开发范围 |

## Phase 1 交付结果

1. 已建立仓库、CMake、C++20、Catch2/CTest 与架构边界检查。
2. 已实现无第三方依赖的 Foundation 公共契约。
3. VS2022 x64 Debug 与 Release 均通过 11/11 CTest。
4. 交付证据见 [`阶段交付/2026-09-03-Phase1-Foundation.md`](阶段交付/2026-09-03-Phase1-Foundation.md)。

Phase 1 没有创建 `modules/`、`hosts/gui/` 或任何 CAD/CAM 示例命令。

## Phase 2 交付结果

1. 已实现 AppKernel 组合根、类型安全 ServiceRegistry 与自研 ModuleRuntime。
2. 已实现缺失依赖、主版本/最低版本冲突、循环依赖与重复服务提供者的启动前检查。
3. 已实现确定性拓扑启动、逆序停止、服务声明核验、Registry Freeze、异常转换和失败回滚。
4. VS2022 x64 Debug 与 Release 均通过 22/22 CTest；Debug 全集连续 10 轮通过。
5. 契约见 [`内核契约/Phase2-应用组合与模块生命周期.md`](内核契约/Phase2-应用组合与模块生命周期.md)，交付证据见 [`阶段交付/2026-09-03-Phase2-Application-Composition.md`](阶段交付/2026-09-03-Phase2-Application-Composition.md)。

Phase 2 没有引入第三方 Production Dependency，也没有实现领域模块；其后按顺序进入 Phase 3 的 Infrastructure Adapter 基线。

## Phase 3 交付结果

1. 五项 Production Infrastructure Dependency 已按不可变提交或官方 SHA3-256 锁定，并集中由 CMake 管理。
2. 已实现 spdlog 人工/JSONL 日志、jsoncons JSON/Schema、toml11 配置、SQLite 控制面持久化和 BS::thread_pool Executor Adapter。
3. 三方类型没有进入 Kernel 公共 API；架构门禁进一步限制第三方实现只能出现在各自 Adapter 私有目录。
4. 第三方错误、异常、非法参数和不支持类型均转换为 Kernel Error；SQLite 复合值/BLOB、TOML Null/日期时间采用 fail-closed。
5. VS2022 x64 Debug 与 Release 均通过 40/40 CTest；Debug 全集连续 20 轮通过；Production-only Release 构建通过且未引入 Catch2。
6. 契约见 [`内核契约/Phase3-基础设施端口与依赖治理.md`](内核契约/Phase3-基础设施端口与依赖治理.md)，交付证据见 [`阶段交付/2026-09-03-Phase3-Infrastructure-Adapters.md`](阶段交付/2026-09-03-Phase3-Infrastructure-Adapters.md)。

Phase 3 没有实现 PersistenceService、TaskRuntime、Scheduler 或任何领域/Host 模块。下一步严格进入 Phase 4 的 Document、ObjectRegistry、Revision 与 Application Transaction。
