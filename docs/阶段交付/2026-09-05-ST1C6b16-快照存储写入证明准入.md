# ST1C6b16 快照存储写入证明准入交付

## 范围与实现

本检查点只修改 Application Kernel 的 Snapshot Persistence、既有单元测试和中文文档，不改公共 API。契约见 [C6b16](../内核契约/ST1C6b16-快照存储写入证明准入.md)。

- 未知 SnapshotWriteDisposition 在数据库索引前拒绝并回滚。
- AlreadyPresent 必须读回同一 SnapshotId，精确 payload 相等后才能建立索引。
- 读回失败保留底层 cause；内容不匹配使用独立稳定错误。
- Created 与合法 AlreadyPresent 保持兼容；失败允许孤立不可变文件，不留下可信索引。

## 红灯与焦点证据

真实 Release 红灯保留于 `build/st1c6b16-red-tests.log`。旧实现对未知 disposition 和不匹配 AlreadyPresent 均返回成功并写入索引；合法 AlreadyPresent 也少一次写入前读回。三分支共 24 条断言，3 条目标断言失败。

修复后同一用例三分支全部通过：两条拒绝路径验证稳定错误且 latestSnapshot 无索引；合法已存在内容验证写入前与后续读取共两次 read，并可正常返回最新快照。
