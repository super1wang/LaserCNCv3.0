# ST1C5a 持久化会话端口与独占基础

## 范围

在 C1a `9da759e` 后继续推进 C5。本节点交付必需的 `IPersistenceBackend::acquireHostSession` 端口、SQLite/Windows 文件独占、显式策略读回、代理转发及组件/进程证据。没有新增第三方依赖或上层模块；进程探针仅在测试构建启用。

**这是 C5a 基础检查点，不是 C5 整体验收。** PersistenceService/AppKernel 初始化尚未调用新会话端口；C5b 必须无条件接入且证明第二 Host 不改写第一 Host 的活动材料，不能据此宣布生产 Host 已强制独占或 Kernel Frozen。完整设计、机制来源及下一步验收见 [C5 契约](../内核契约/ST1C5-持久化Host独占与耐久准入.md)。
