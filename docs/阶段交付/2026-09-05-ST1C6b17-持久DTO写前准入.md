# ST1C6b17 持久 DTO 写前准入交付

## 范围与实现

本检查点只修改 Application Kernel 的 Journal、Task、Workflow 持久化写入口、既有测试和中文文档，不改公共 API。契约见 [C6b17](../内核契约/ST1C6b17-持久DTO写前准入.md)。

- Journal 在序列化和事务前验证 ObjectChangeKind、HistoryMutationKind 及其 before/after/历史字段形状。
- Task acceptance 不再把未知资源枚举写入 acceptance payload，终态写入区分未知状态、合法非终态及非法 Error 元数据。
- Workflow definition digest/checkpoint 共同验证定义枚举；checkpoint 另验证 Workflow/Step 状态和全部已持久 Error 的 category/severity。
- 拒绝路径不建立 Journal、Task 或 Workflow 记录；合法 wire 版本、字段、枚举数字和摘要保持不变。

## 红灯与修复证据

真实 Release 红灯保留于 `build/st1c6b17-red-tests.log`。旧实现三项 CTest 共 67 条断言，15 条目标断言失败：Journal 四种非法材料全部写入成功；Task 两种资源枚举和两种 Error 枚举写入成功，未知 TaskState 只被误归 `TaskNotTerminal`；Workflow 六种非法定义/状态/Error 材料均获成功或定义摘要。

修复后同三项 CTest 全部通过，覆盖 Journal 4、Task 5、Workflow 6 个分支；每条拒绝均核对稳定错误码和持久查询无新增记录。既有合法 Journal、Task、Workflow 往返、错误 cause、恢复和崩溃用例由 Release 全集继续证明。

## 最终门禁

普通 Debug/Release 注册清单为 480 项，ASan 为 483 项。C6b16 的 222 项选集加入本节点 3 项后为 225 项且无重复：Debug 225/225；ASan 三轮共 675 次执行全部通过且无 sanitizer 报告。Release 额外运行完整 480/480，包含并发压力、崩溃注入、进程恢复、架构边界和 Headless 往返，总耗时 1063.04 秒。

纯生产 Release 共 31 个 vcxproj，通过且不含 test/probe/benchmark/ASan/Catch/CTest；边界检查覆盖 71 个公共头、141 个生产源。公共头未修改，build 红灯、构建、测试和选集材料仅留本机。

本节点不是 C6 大节点，不推远端。下一步继续 Host、State、Task Error cause 及其他持久 DTO/格式，再进入 C6c/d 的统一预算、同步边界和终态保留。
