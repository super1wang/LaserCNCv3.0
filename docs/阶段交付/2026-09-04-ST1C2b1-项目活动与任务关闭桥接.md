# ST1C2b1 项目活动与任务关闭桥接

## 状态与范围

承接 C2a `2259c5a`，仅覆盖 C2b1：普通 Project-only 执行、无文档 Task 的项目归属及关闭保护。实现、专项、完整 Debug、重复及纯生产门禁通过，形成本地检查点，不是 C2b 全项或整体冻结签核。未新增三方库，未扩展上层模块。

完整剩余范围见 [C2b 契约](../内核契约/ST1C2b-项目活动与生命周期控制.md) 和 [ST1C 计划](../内核契约/ST1C-补充审计与剩余执行计划.md)。

## 交付内容

1. Project-only Command/Query 校验项目真实存在且 Open，并取得项目活动租约；文档请求继续由文档租约间接持有项目。同步租约保留至 trace/metrics 发布结束，校验拒绝和 Handler 异常均释放。
2. Task 提交期间的短期租约覆盖 Scheduler 准备、持久接受和激活；提交后由 Scheduler 的真实 request.projectId 提供长期关闭阻塞，不再漏掉空项目下的任务。
3. 项目关闭先封闭准入，再检查 Task 和既有文档子树；被阻塞保持 Open，不改写虚假 Closed。另一个项目可以正常关闭。
4. Task 已进入终态但 `completionReady` 为 false 时仍算活动，包括终态 trace/metrics、持久化及错误记录阶段；CancelRequested 不视为完成。
5. Task 接受写入失败撤销 prepared 记录，允许原请求干净重试；执行器提交异常形成 Failed 终态，不泄漏活动。此处保留“命令已接受，任务随后失败”的既有异步回执语义。
6. 只增加只读项目活动计数重载及内核装配私有连接；不新增 Host 的可变准入旁路，不改变持久化格式。`ProjectLifecycleSnapshot.activities` 仅统计短期租约，不能单独作为可关闭判据。
