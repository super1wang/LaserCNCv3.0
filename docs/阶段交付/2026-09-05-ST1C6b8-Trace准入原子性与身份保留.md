# ST1C6b8 Trace 准入原子性与身份保留交付

## 范围

本检查点只修改 Application Kernel 的 Trace 内存服务和内核测试，不增加 GUI、CAD、CAM、设备、网络或产品 CLI。契约见 [ST1C6b8](../内核契约/ST1C6b8-Trace准入原子性与身份保留.md)。

## 实现结果

- `startSpan` 在发布活动身份前完成 completion 和句柄分配；未准入句柄保持未激活，失败析构不制造 abandoned 记录。
- 活动表插入成功后才激活句柄，随后以无额外分配的移动交付所有权。
- 冲突文案明确为“活动或仍保留期间占用”，与容量为一时淘汰后可复用的实现一致。
- 新增独立分配故障探针，以及身份窗口复用、服务所有者先析构两项常规回归。

## 红灯与门禁

Release 红灯逐次注入 14 个分配点，其中后 6 个点复现：异常返回后活动数量增加、同 ID 不可重试、清理后仍有孤儿且 exporter 次数不符。修复后 Release 同样 14/14 注入点全部保持原子性。

最终注册清单为 470 项。本节点按与 C6b7 相同的 Foundation/Kernel/Infrastructure/架构/Headless 精确选集加入三项新测试：Debug 215/215、Release 215/215；ASan 215 个名字各连续三次，即 645 次执行全部通过且普通输出无 AddressSanitizer 报告。独立分配探针在 Release 与 ASan 各穷举 14 个分配点，ASan 三轮日志均有成功标记；Debug 的分配探针仅为链接/启动 smoke。纯生产 Release 构建通过，目录不包含测试目标；边界检查覆盖 71 个公共头和 141 个生产源文件。公共头未改。
