# ST1C6b3：Schema 根类型准入

## 范围与实现

基线 e1aa559，仅 Foundation/Infrastructure 内核实现、回归与中文文档。依据 [契约](../内核契约/ST1C6b3-Schema根类型准入.md) 修复 Schema 工厂接受未知枚举、jsoncons 将其弱化为 Any 的缺陷。保持合法八种根类型、显式 Any 的额外约束、公开头及持久格式不变。最终 Debug/Release 选集各 147/147、ASan 同选集 441/441、探针另 3/3 和生产/架构通过。完整 C6–C8/ST1D 尚未关闭，本节点本地提交，完整 C6 大节点完成后再推送远端。

## 红灯与修复

- st1c6b3-red-build.log 构建退出 0；st1c6b3-red-tests.log 两项 0/2、0.61 秒、退出 8。穷举未定义值在正常 metadata 下被工厂接受；错误 metadata 下返回旧 constraints 错误而非根类型拒绝。真实 jsoncons 对 8/255 两个代表值接受七类 Value。错误优先级的负例和真实错误准入均保留，不把前者全部描述为执行副作用。
- Schema::create 以八个显式 case 允许合法值，其他值先返回 Validation/Foundation.SchemaKindInvalid。jsoncons 的 schemaType 只有 Any 返回 nullptr，默认分支抛错进入已有 SchemaBackendFailed 边界；没有新增公共私有构造旁路来覆盖不可合法到达的后端分支。
- 新增四项，覆盖 496 次未知根/metadata 组合、八种合法根元数据、两个代表值的后端拒绝链，以及 56 对合法类型组合和三个 Any 附加约束场景。这些内部场景不能按调用次数充当同等数量的独立 CTest。
- st1c6b3-green-build.log 构建退出 0；Schema/JSON/版本相关 20 项各三次，60/60、15.81 秒、退出 0，日志和明细另存 st1c6b3-green-tests.log、green-details.log、green-manifest.json（后两者同前缀）。

## 复现与边界

使用既有 Windows x64 / MSVC 19.44.35216.0 / CMake 3.29.3、锁定依赖。重型构建串行 --parallel 1 /nodeReuse:false，选集 -j 2；同树清单、执行和 LastTest 副本归档串行。严格 ASan preset 不变，普通结果与健康/故意内存错误探针分开计数。

```powershell
$names = 'J:/Code/LaserCNCv3.0/build/st1c6b3-selected-tests.txt'
cmake --build --preset vs2022-debug --parallel 1 -- /nodeReuse:false
ctest --preset vs2022-debug --show-only=json-v1 --tests-from-file $names
ctest --preset vs2022-debug -j 2 -V --tests-from-file $names
cmake --build --preset vs2022-release --parallel 1 -- /nodeReuse:false
ctest --preset vs2022-release --show-only=json-v1 --tests-from-file $names
ctest --preset vs2022-release -j 2 -V --tests-from-file $names
cmake --build build/production-only --config Release --parallel 1 -- /nodeReuse:false
cmake --build --preset vs2022-asan --parallel 1 -- /nodeReuse:false
ctest --preset vs2022-asan --show-only=json-v1 --tests-from-file $names
ctest --preset vs2022-asan -j 2 --repeat until-fail:3 -V --tests-from-file $names
ctest --preset vs2022-asan -j 1 -V -R '^integration.kernel_asan_probe_'
cmake -DLCNC_SOURCE_ROOT=J:/Code/LaserCNCv3.0 -P cmake/VerifyKernelBoundaries.cmake
```
