# ST1C4c：恢复失败准入与事务导入矩阵

## 状态与范围

基线 `679942c`，承接 [C4 契约](../内核契约/ST1C4-可信装载与事务导入.md)。本次统一门禁通过：Debug 407/407、定向 ASan 29 项各 3 次（87/87）、纯生产 Release、真实 Host 编译探针及架构检查。C4a/b/c 已形成可信装载正确性大节点，按计划提交并推送远端；整体 Kernel 仍未 Frozen。只新增内核测试、CTest 源文件登记及中文文档；不修改生产实现、持久格式或上层模块，不提供测试专用装载后门。

本节点验证 C4b 封闭后的真实执行路径，以及既有失败状态契约；未发现需要修改生产实现的新缺陷。不是把仅返回 Error 的断言当作通过，而是同时比较状态、原始持久行、执行次数、事件与后续恢复。

## 新增矩阵及可检查证据

新增文件 [document_recovery_admission_tests.cpp](../../tests/unit/runtime/document_recovery_admission_tests.cpp)，通过普通模块注册 DocumentWrite 命令、Query、异步 Command/Task、Workflow、Script，使用实际 SQLite、文件快照与 BsThreadPoolExecutor。种子由真实命令产生两个对象、非零修订、Journal、History 和已发布事件；先以健康对照证明五类入口实际可执行，再检验拒绝。恢复行为和重入通过公开生命周期及对象验证回调触发，不增加生产 friend/注入接口。

| 用例 | 场景数 | 验证范围 |
| --- | --- | --- |

| Governed batch import persistence faults… | 6 | Begin/Journal Execute/Commit × 返回错误/抛异常。两个候选已产生且事件已暂存，持久失败后对象、全部修订、Journal、History 和目录不变，事件未交付；解除一次性注入后显式重试成功，新 Host 不重放 Handler，并实际 Undo/Redo |

## 与既有矩阵的合并覆盖

- C4b 的 `Governed document import validates candidates without implicit migration` 覆盖第二对象的未知类型/版本、无效值、重复 ID、显式旧 Schema、Capability 和 Scope；不是本文件重复增加的用例。
- [persistence_service_tests.cpp](../../tests/unit/runtime/persistence_service_tests.cpp) 覆盖 durable 未支持版本的 open 拒绝及 Detached 保留、Transient/失败幂等状态；[asset_state_tests.cpp](../../tests/unit/runtime/asset_state_tests.cpp) 覆盖损坏/缺失资产、历史资产、open/Undo 拒绝及事务准入。
- C3 的 Journal/Snapshot/混合来源及归属/Detached/Removed 墓碑矩阵继续保留；C2 的真实并发协调关闭和整体准入继续回归。本次两种重入场景不冒充所有线程交错证明。
- 真正的 Host 编译拒绝探针仍由 Debug 全集执行；它只证明当前 MSVC 的源码访问边界，不是 ASan 运行期测试，也不表示同进程恶意代码隔离。

## 开发期失败记录

1. `build/st1c4c-initial-tests.log`：0/1，26.83 秒，退出 8。八种故障场景的健康事件计数均为零，原因是测试丢弃了 RAII EventSubscription 临时对象。改为持有订阅后通过；这是夹具错误，不是生产事件丢失缺陷。
2. `build/st1c4c-matrix-tests.log`：2/3，48.39 秒，退出 8。运行期及导入故障通过，四个 bootstrap 场景错误地要求 Failed Host 普通 shutdown 成功。代码既有契约是 Kernel.AppKernelCannotStop，最终释放由析构执行；修正为精确拒绝断言，并保留新 Host 接管验证，不修改生产语义迎合测试。
3. `build/st1c4c-expanded-tests.log`：4/4，52.67 秒，退出 0；`build/st1c4c-reentry-tests.log`：1/1，2.95 秒，退出 0。上述发生在分组开发阶段，不代替最终五项统一版本及全量门禁。

原始失败日志、数据库和快照保留在 build 下；夹具使用唯一 evidence 目录。C4b 公开 attach 的真实编译红灯另见 [C4b 交付](2026-09-04-ST1C4b-封闭公开镜像装载.md)，不得用本次夹具失败替代该证据。
