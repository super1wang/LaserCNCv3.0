## 红灯与实现

- st1c6b4-red-build.log 构建退出 0；五个新负向 CTest 在旧实现 0/5、0.43 秒、退出 8，明细保留 st1c6b4-red-tests.log / red-details.log。未知 mode/filter 可注册，跨版本通知被覆盖，公开 ID 复用使旧排队项或已提取批次改交新 callback，跨实例合并也错误计为 coalesced。
- subscribe 在插入前拒绝未知枚举，新增 Event.InvalidDeliveryMode / Event.InvalidFilterKind；不改变空 callback 原错误。内部每个注册实例有不可变共享身份标识，排队和 drain 核对该标识，Notification 合并同时核对完整 Version。无公共头改动，无持久身份或数据库迁移。

- 本轮新增八项。非法枚举 760 次调用、合法组合八种和版本三种均是内部场景，不按循环次数冒充独立 CTest。双线程夹具用有界屏障建立 drain 提取后取消/复用的交错；不靠 sleep 猜测调度，也不宣称是完整线程交错穷举。
