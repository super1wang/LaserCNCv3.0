## 状态与范围

## 行为修复

1. 旧实现对所有 Workflow 检查点要求文档 Open，因此完成/取消后合法关闭或删除文档，会导致下次 Kernel 启动失败。
2. 新实现对终态从已校验 DocumentCatalog 建立文档到项目的历史归属索引，包括 Removed 墓碑；核验失败返回 `Workflow.RecoveryOwnershipUnavailable`。索引仅是本次恢复的认证材料，不成为第二套可变身份源。
3. 非终态继续核验运行时文档 Open 且归属一致，仍拒绝关闭容器；不因历史 checkpoint 自动创建或打开任何项目/文档。
4. 终态不转换步骤为 Waiting，不设置尝试重放标记。终态 advance/cancel 返回原结果且不执行 Handler；定义存在性、版本/摘要、步骤集合和完成顺序检查保留。
5. 目录读取失败/异常使整个恢复失败，不部分安装实例；销毁失败 Host 后可用干净 Host 重试。恢复后项目与文档目录保持原生命周期状态。
