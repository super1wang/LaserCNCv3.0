## 实现

1. CommandDescriptor 新增固定 LifecycleOperation；SideEffectLevel 尾部新增 LifecycleControl，保留旧枚举编号。Project create/open/close 与 Document create/open/close/remove 使用原状态机。
2. ModuleRegistrar 登记精确命令贡献；不接受任意 Handler，注册检查失败仍触发治理回滚。原四条 Handler 注册通道拒绝生命周期元数据。Host 只读注册器和 Gateway 边界不变。
3. 固定操作只取得整体准入，不拿自身目标的普通执行租约；仍受 Capability、版本、Schema、精确 Scope、真实所有者及其他活动保护。空 Object 参数、无业务 Revision 前置条件、无幂等缓存/自动重放。
4. 成功返回固定身份/状态；结果校验及日志错误记录到 postExecutionErrors，不伪装未执行。持久化失败保留原状态机的 Failed 与错误链。
5. 新重启回归发现 Removed 墓碑可被 create 覆盖。Runtime create 改为先预留内存身份，再认证持久目录；已存在/读取失败不写入、不残留预留，可按真实状态重试。Detached 身份不能通过 create 清空；既有错误所有者错误码保留。公开 attach 的完整收口仍在 C4。
6. 静态复核补充：文档控制把请求父项目的租约带到 close/remove 的状态锁内再次匹配；open 在认证目录处再次匹配请求所有者，避免只依赖一次前置归属查询。辅助方法保持私有，公开 Runtime 原路径复用同一实现。此前运行中的全集标为中间证据，最终代码重新执行门禁。
