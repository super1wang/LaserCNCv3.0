# ST1C6b15 版本解析策略枚举准入交付

## 范围与实现

本检查点只修改 Application Kernel 的 Command/Query Registry 与 Runtime、既有单元测试和中文文档，不增加公共 API。契约见 [C6b15](../内核契约/ST1C6b15-版本解析策略枚举准入.md)。

- Command/Query Registry 在查找前仅接受 Exact、Compatible。
- 公开 descriptor 查询与 ExecutionGateway 请求共享相同的 InvalidVersionResolution 错误语义。
- Runtime 内所有生成 `versionResolution` 文本字段的请求错误、Trace、日志和持久签名路径统一通过闭集名称转换；实际非法请求按既有流程留下的失败 Trace 显示 unknown，不再冒充 compatible。
- 非法请求不调用 handler，也不进入 Schema、Capability、事务、幂等或外部 Effect 执行。
- Exact/Compatible 正向选择、Deprecated、NotFound 与 UnsupportedVersion 保持不变。

## 红灯与焦点证据

真实 Release 红灯保留于 `build/st1c6b15-red-tests.log`。旧实现对公开 Registry 与实际 Runtime 的四次未知策略都返回 UnsupportedVersion；两条失败 Trace 均记录 compatible。Runtime 用例 23 条断言中 4 条失败，Registry 用例 6 条断言中 2 条失败；两个 handler 的零调用断言已证明缺陷是错误分类/观察失真，而不是已发生业务执行。

修复后两项焦点 CTest 全部通过：Registry 同时覆盖 Command/Query 公开查询，Runtime 同时覆盖 ExecutionGateway 错误、handler 零调用、两条失败 Trace 的 unknown 属性和失败终态。
