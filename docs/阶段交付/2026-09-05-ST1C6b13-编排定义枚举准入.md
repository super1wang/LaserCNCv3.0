# ST1C6b13 编排定义枚举准入交付

## 范围与实现

本检查点只修改 Application Kernel 的 WorkflowRegistry、ScriptRegistry、既有单元测试和中文文档，不增加公共 API。契约见 [C6b13](../内核契约/ST1C6b13-编排定义枚举准入.md)。

- Workflow 注册前显式验证 StepKind 及可选 PredicateKind。
- Script 注册前显式验证 NodeKind、可选 PredicateKind，并对 Wait 节点验证 WaitTarget。
- 五类未知枚举分别返回稳定的 Validation Error，不写入注册表、不等待运行时猜测。
- 公共枚举数字、DTO、定义摘要、持久格式、SQLite 版本和依赖均不变。

## 红灯与焦点证据
