# ST1C6b5 消息回调资源与异常边界

## 范围与状态

基线 `3a45699`，承接 [C6b4 消息身份](ST1C6b4-消息准入与订阅身份.md)。只调整 EventBus 私有回调持有、取消/析构与投递复制边界，不改公共头、持久格式或上层模块。七项负向回归在旧实现 0/7；修复后的消息专项 23 项各十次通过。Debug 全集 449/449、Release 选集 172/172、ASan 同选集三次 516/516、探针另 3/3 和生产/源边界通过，完整证据见 [交付记录](../阶段交付/2026-09-05-ST1C6b5-消息回调资源与异常边界.md)，不以本节点代签 C6–C8/ST1D。

## 生命周期规则

1. 注册项用私有共享所有者持有不可替换的 EventCallback；锁内只获取所有者快照，不复制用户定义 callable。Immediate 保留发布时匹配的实例集合，Queued 仍在提取后按 C6b4 私有身份再次核对当前订阅；不把取消后的同名新注册当成旧订阅。
2. 每次实际投递在锁外复制一次独立 EventCallback，然后调用副本。可变 lambda 的内部状态仍不自动写回注册原件；不是直接并发调用同一个可变原件。复制构造可以重入 Bus；调用和资源释放也不持有注册表锁。
3. cancel 先解除当前令牌的弱引用，再锁内 extract 注册节点，最后锁外释放节点及捕获资源。资源析构若重新注册相同 ID 并再次 cancel 旧令牌，旧令牌已经失效，不能误删新实例。重复取消仍无效。
4. Bus 析构先锁内标记 closed、移走整个注册表并清空队列，再锁外释放注册资源；捕获资源析构可以取消尚存令牌，不再自锁。重复 ID 拒绝和插入异常路径保有一个锁外回调所有者，不在临时注册项回收时销毁最后一个用户资源。
5. 已取得共享快照的投递会继续持有原回调，取消不排空它，也不能撤回正在进行的用户复制/调用。捕获资源可能延迟至该快照释放才销毁。这是寿命保护而非 join、执行截止确认或可靠消息保证。

## 异常与兼容边界

- 用户复制构造和 callback 调用的标准异常及未知异常都记录为该订阅的 `Event.SubscriberFailed`，继续其他候选。Immediate 不再把用户复制失败升级为整个 `Event.PublishFailed`；Queued 不再因用户复制失败直接逸出并放弃剩余批次。已排队候选及其他 Immediate 订阅照常处理，投递报告成功仍须检查 failures。
- 发布在交换新队列前预留失败条目容量；drain 在提取候选前预留批次与失败条目容量。此安排减少准备失败后的部分消费，但不承诺资源耗尽时能构造 Error 或报告；仍有字符串、Value、vector 等分配，不能宣称全入口 noexcept、全局 OOM 回滚或不丢消息。
- 测试中 callable 主动抛 `bad_alloc` 只证明该类用户异常被隔离，不是系统内存耗尽认证。调用者在进入 subscribe 前构造/复制按值参数时的异常不属于函数体可拦截范围；公开 subscribe/drain 本身也未声明 noexcept。
- 用户析构必须遵守 C++ 不抛异常要求。重入不代表可无限递归发布、从正在执行的方法内销毁 Bus，或与其他线程并发销毁 Bus；所属对象及引用必须保持有效。相同令牌对象的并发 move/cancel 仍不受支持。
- 多个 publish/drain 调用可能并行复制同一回调原件；用户自定义复制及其引用的共享状态须支持这种并发。此前注册表锁附带串行复制，现在不再提供这项隐含串行性；本节点不增加用户代码串行执行器或递归锁。独立副本不代表被引用的外部对象自动线程安全。
- 与 C6b4 相比，公开方法、DTO 和错误码集合不变；用户复制异常由整体/逸出失败变为逐订阅失败，复制时点移至各次投递前，捕获原件寿命可被在途快照延长，均是必须告知消费者的行为变化。

## 测试证据与未闭合项

新增 11 项 CTest：取消/重复拒绝/Bus 析构释放重入三项；Immediate/Queued 复制重入两项；两种模式下复制异常隔离两项（各含 runtime_error、未知 int、主动 bad_alloc 三场景）；独立可变副本、复制中取消并复用身份、混合 Immediate/Queued 故障隔离、真实双线程复制中取消与资源延寿四项。模式和内部异常循环不重复计为 CTest 数量。

死锁回归由同一独立 CTest 进程中的 10 秒有界看护线程保护，超时打印 `event-reentry-deadline-exceeded` 并退出 86，防止分离持有悬空引用的线程；成功路径兑现 promise 并 join。双线程测试以 5 秒有界 promise 屏障确定交错，不用 sleep 猜测，不证明所有线程交错。

总队列/订阅/Value 字节预算、失效候选保留、复制与回调耗时和异步 Task 契约仍归 C6c/d。新增共享回调原件的分配/引用成本与既有身份标识、全队列复制成本须由 C7 实测。下一项继续 Observability 的未知枚举、合法终态、数值累加及出口 DTO 边界，再审计其余公共类型/持久格式；源代码风险必须配真实回归，不仅登记便视为通过。
