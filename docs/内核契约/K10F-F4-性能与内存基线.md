# K10F-F4 性能与内存基线

## 状态

F4A 测量工具已建立，正在采集正式基线；尚未签发 F4 验收。范围仅为内核及测试代码，不增加产品 CLI、领域模块或第三方库。F5 与 Kernel Frozen 仍未完成。

## 可复现入口

`tests/benchmark/kernel_benchmark.cpp` 为 Windows 测试目标，依赖现有内核、SQLite/JSON/Hash/Snapshot 适配器及 Windows SDK Psapi。`LCNC_BUILD_TESTING=OFF` 时不生成它。运行脚本使用 PowerShell 7，按每个数据集七组、每组独立进程、全部串行执行：

```powershell
cmake --preset vs2022-debug
cmake --build --preset vs2022-release --target lasercnc_kernel_benchmark --parallel 1 -- /nodeReuse:false
pwsh -NoProfile -ExecutionPolicy Bypass -File tests/benchmark/RunKernelBaseline.ps1
```

`-ExecutionPolicy Bypass` 仅作用于本次脚本进程，不修改系统执行策略。可指定 `-ObjectCounts 1000` 预检。默认 1k、10k、100k 对象；操作预热一次、采样五次；生命周期十轮。运行目录位于忽略的 `build/kernel-baselines/run-*`，每轮独立保留日志、原始 JSON 和 SQLite/Snapshot 文件，无自动删除。索引记录源提交及脏工作区状态、源码/脚本/程序/报告 SHA-256、CPU、系统和采样参数。脚本逐组验证退出码、成功标记、报告范围、配置和样本数，不允许把 Debug 数据当作正式 Release 基线。

## 数据与计时边界

- ObjectId 为固定九位数字后缀，载荷为单个 `payload` 字段的 128 字节字符串；类型版本 1.0.0，Durable，真实字段验证器，无引用、无 Asset。实际 Value 序列化字节数写入报告。该数据集不代表 OCCT 形体、大资产或任意深度 Value。
- 每个操作保留原始样本、最小值/中位数/最大值、校验耗时和结果存活时内存。准备、完整结果校验、返回对象析构均在计时外；API 内部工作和成功/错误结果解包仍包含在操作中。计时采用单调时钟；不清空 OS/文件/分配器缓存。五次样本仅建立本机基线，不作尾延迟或跨机器性能保证。
- `component` 使用公开组件组合，初始批量创建 N 对象并提交一次，初始 Revision=1。分别测 Document snapshot、Transaction begin（之后回滚）和单对象 commit；commit 的 begin/replace 在计时外。SQLite 模式的初始化会写 N 对象 Journal，不能与网关组初始化成本混为一谈。
- `gateway` 使用 AppKernel 和 ExecutionGateway，attach N 对象，初始 Revision=0；SQLite 组另保存基线 Snapshot。直接空 handler、Global Query/ReadOnly Command 是框架开销对照；Document Query/ReadOnly Command 包含当前文档快照复制。写命令包含完整事务、候选校验、提交与集成；不能称作纯框架开销。六次写入保留六条 History，Undo/Redo 固定反复应用最后一条；恢复起始游标的反向命令在计时外。每次写请求（含 Undo/Redo）使用唯一请求 ID。
- `journal` 使用实际 SQLite 及 N 对象 Snapshot，六条单对象变更尾部。append 的来源命令在另一内存内核准备，计时只含 Journal 写入；recover_material 返回持久化恢复材料，bootstrap_recovery 包含内核恢复/安装。恢复的配置/打开连接在 bootstrap 计时外；校验对象、Revision、History 范围，不把只读 Snapshot 当作完整启动恢复。
- `lifecycle` 独立十轮配置、bootstrap、attach，SQLite 组还保存初始 Snapshot；每轮记录启动/种子、shutdown/析构耗时和销毁后内存。全部十轮记录，不按操作预热规则排除首轮。操作组的 seed 耗时从 bootstrap/attach 开始，不含之前的模块注册与适配器配置；生命周期启动计时则包含这些配置。
- SQLite 实际 `journal_mode/synchronous/page_size/cache_size/foreign_keys` 写入报告，不人为关闭刷盘。NullLog 排除日志文件 I/O，但网关的日志组织与 Trace 集成仍属于测量路径。

## 内存解释

记录工作集、私有提交内存和进程峰值工作集，单位字节。`memory_before` 与 `memory_result_live` 不是采样期间的独立峰值；进程峰值包含初始化、校验以及该进程之前的所有操作。操作结果校验会额外复制/枚举完整对象，因此也可能抬高后续工作集和进程峰值，不能将此峰值归因于单次被测调用。

生命周期销毁后的内存用于观察跨轮次趋势，既包含内核释放后的分配器缓存，也包含小规模报告积累，不能单凭未立即回落断言泄漏或无泄漏。F5 地址检查器和可靠性门禁另行验证。
